# picasso and Determinate Nix

A study for [#96](https://github.com/h0ffmann/picasso/issues/96): what Determinate Systems offers, where
picasso already depends on it, a side-by-side comparison, and what picasso can do by April 2027. Read
[`study.pdf`](study.pdf). `study.html` is the source and uses the whitepaper's look; `node render.mjs`
prints it again (Playwright on the module path, network for Google Fonts).
