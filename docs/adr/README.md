# Architecture decision records

One file for each decision, `NNNN-short-title.md`, numbered in order. An ADR has a status
(Proposed, Accepted, Rejected, Superseded by NNNN), the context, the decision, the alternatives
and the consequences. Do not edit the decision of an Accepted ADR: write a new ADR that
supersedes it.
